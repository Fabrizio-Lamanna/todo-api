# 📝 Todo API - Spring Boot

Backend de una aplicación **ToDo List** desarrollada con Spring Boot.
---

## 🚀 Tecnologías utilizadas

- Java 17
- Spring Boot 4.0.5
- Maven
- Spring Web (API REST)
- Spring Data JPA
- PostgreSQL Driver
- Validation
- Lombok
- YAML Configuration
